# 🥢 お好み焼き 運用パック

お好み焼き店の Instagram 運用を手伝う、ブラウザで使うツールです。
お店の情報を一度登録すると、Google の AI「Gemini」が、そのお店に合った投稿の企画、動画の台本、撮影の準備、月ごとの振り返りなどを作ります。

[Streamlit](https://streamlit.io/) で作っていて、自分のパソコンで動かします。

## できること(7つの機能)

| # | 機能 | 内容 |
|---|------|------|
| 1 | トレンド調査 | Google 検索を使って、飲食店の Instagram で今はやっていることをまとめます。自分で調べた最新情報をメモとして保存し、ほかの機能に渡すこともできます。 |
| 2 | 月次企画 | 1か月分の投稿案(ストーリー30本・リール10本・フィード10本)を、日付・テーマ・撮る素材の表にします。Excel やスプレッドシートに貼り付けられます。 |
| 3 | 動画企画(月4本) | リール動画4本の台本、撮る順番、テロップ、BGM の雰囲気を作ります。 |
| 4 | 現地撮影の準備 | 撮るものリスト、当日の進行表、お店に送る事前連絡文を作ります。 |
| 5 | 月次の振り返り | Instagram の数字が入った CSV を読み込んで集計し、良かった点、改善点、次の月の提案をまとめた報告書を作ります。 |
| 6 | プロフィール見直し | プロフィール文を3案(150文字以内)作ります。プロフィール画像を入れると、AI が見て改善点を出します。 |
| 7 | 共通テンプレ | フィードとリールの最後に置く共通ページ、キャプションの最後に付けるお店情報、案内文を作ります。 |

どの結果も「コピー」ボタンでコピーしたり、テキストファイルで保存したりできます。
登録した NG ワードが結果に入っていたら、警告が出ます。

## 必要なもの

- Python 3.10 以上
- Gemini の API キー([Google AI Studio](https://aistudio.google.com/apikey) で無料で発行できます)
- インターネット接続

## インストール

```bash
git clone <このリポジトリのURL>
cd sns-pro-tool

# (おすすめ)仮想環境を作る
python3 -m venv .venv
source .venv/bin/activate      # Windows の場合: .venv\Scripts\activate

pip install -r requirements.txt
```

## .env の作り方

`app.py` と同じフォルダに `.env` という名前のファイルを作り、次の1行を書きます。

```
GEMINI_API_KEY=あなたのAPIキー
```

> ⚠️ `.env` は `.gitignore` に入っているので GitHub には上がりません。API キーはほかの人に見せないでください。

## 起動方法

```bash
python3 -m streamlit run app.py
```

ブラウザが開いたら、左のメニューの「お店を登録・直す」でお店を登録してから、使いたい機能を選びます。

お店の登録例は `stores.sample.json` にあります。これを `stores.json` という名前でコピーすると、例のお店がすでに登録された状態で始められます。

使う AI のモデル名や、企画の本数などの設定は、`app.py` の上の方にまとめてあります。

## ファイル構成

| ファイル | 内容 |
|----------|------|
| `app.py` | アプリの本体 |
| `requirements.txt` | 必要な Python パッケージ |
| `stores.sample.json` | お店の情報の例(架空のお店) |
| `sample_insights.csv` | 「5. 月次の振り返り」で試せるサンプルデータ(架空のデータ) |
| `.env` | API キー(自分で作る。公開されません) |
| `stores.json` | 登録したお店の情報(自動で作られる。公開されません) |
| `trend_memo.json` | 保存したトレンドのメモ(自動で作られる。公開されません) |

## ⚠️ 個人情報についての注意

- 入力した内容(お店の情報、メモ、CSV の中身、画像)は、AI で処理するために Google の Gemini API に送られます。**お客さんの名前や連絡先など、個人情報は入力しないでください。**
- 無料枠の Gemini API では、送った内容が Google のサービス改善に使われることがあります。くわしくは [Gemini API の利用規約](https://ai.google.dev/gemini-api/terms) を確認してください。
- `stores.json`、`trend_memo.json`、`sample_insights.csv` 以外の CSV は `.gitignore` で除外していますが、公開する前に `git status` で、上がるファイルを必ず確認してください。
- AI が作った文章には、事実とちがう内容がまじることがあります。投稿する前に必ず人が確認してください。
